
=== PANDUAN LENGKAP ryanx.my.id ===

1. KETERANGAN SETIAP FILE & KODE
---------------------------------
- index.html: 
  Single Page App. Ada router route() untuk pindah feed/login/register/members/profile/admin.
  Tailwind via CDN biar minimalis. Semua fetch pakai Authorization: Bearer <token>.
  Penjelasan fungsi:
    authHeader() = ambil token dari localStorage
    fetchMe() = cek token valid ke /api/auth/me
    renderFeed() + loadFeed() = tampilkan posting global
    createPost() = POST /api/posts
    likePost() = toggle like
    renderMembers() = GET /api/users -> ini menu Daftar Orang yang kamu mau
    renderProfile() = edit profil sendiri
    renderAdmin() = kelola crowd db1 (user, post, stats)

- schema.sql:
  3 tabel: users (id uuid, username unique, email unique, password_hash, display_name, bio, avatar_url, role), posts (id, user_id FK, content, created_at), likes (post_id+user_id unique). Index buat cepat.

- wrangler.toml:
  Binding D1 dengan nama variable DB, sesuai dengan yang dipanggil di Functions env.DB

- functions/api/_auth.js:
  Core auth: hashPassword pakai SHA-256 + salt, signJwt & verifyJwt pakai HMAC SHA-256 Web Crypto (jalan di edge). getUserFromRequest baca header Authorization.

- functions/api/auth/register.js: POST, validasi, insert user, return token
- functions/api/auth/login.js: POST, cek hash, return token
- functions/api/auth/me.js: GET profil sendiri, PUT update profil (display_name, bio, avatar_url)
- functions/api/posts/index.js: GET feed join users + like_count, POST buat post, DELETE hapus (owner/admin)
- functions/api/posts/like.js: toggle like/unlike
- functions/api/users/index.js: GET semua user untuk Daftar Orang (butuh login)
- functions/api/admin/stats.js: GET hitung users/posts/likes, hanya admin
- functions/api/admin/users.js: PUT ubah role, DELETE hapus user

2. CARA JALANKAN BIAR BERJALAN BAIK
-----------------------------------
A. Siapkan D1:
   Cloudflare Dashboard > Storage & Databases > D1 > pilih ryanx-db > Console > paste schema.sql > Execute
   Cek tabel sudah ada.

B. Siapkan Pages:
   Pages > ryanx-id > Settings > Functions > D1 database bindings > Add binding > Variable: DB, Database: ryanx-db > Save
   Settings > Environment variables > Add > JWT_SECRET = buat string acak 32 karakter > Save

C. Deploy:
   Upload zip ini ke github: extract, git add ., git commit -m "ryanx sosmed v1", git push origin main
   Pages akan auto build (karena Pages Functions tidak butuh build command)
   Tunggu deploy selesai, buka ryanx-id.pages.dev

D. Domain:
   Pages > Custom domains > Set up custom domain > ryanx.my.id > ikuti CNAME

E. Admin pertama:
   Register di website dengan username admin, lalu D1 Console: UPDATE users SET role='admin' WHERE username='admin'; 
   Refresh, menu Admin muncul.

3. ALUR PENGGUNA
----------------
- Pengunjung baru -> Register -> langsung dapat token -> masuk Feed
- Feed: semua postingan semua orang kronologis (tanpa algoritma)
- Daftar Orang: GET /api/users, lihat semua anggota, tanpa pertemanan
- Pengaturan Akun: edit nama, bio, avatar
- Admin: lihat stats, ubah role, hapus user/post yang melanggar
